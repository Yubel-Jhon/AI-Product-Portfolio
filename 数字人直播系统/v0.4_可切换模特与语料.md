# v0.4 · 可切换模特 / 语料库（mod 化）

> 目标：把 v0.3 的「一张页写死一个模特、一个 faq.json 一个语料」，改成**像 Minecraft 装 mod 一样——丢文件夹进去就能在控制台里选**。
> 结果：加了一层「配置 + 控制台」，模特 9 个（8 个 Live2D 官方样例 + 御姐立绘）、语料 1 个（盲盒带货），切换实时生效，不改一行代码。

## 二、加一个新模特（像装 mod）

往 `src/live2d_page/Resources/models/` 丢一个文件夹：

```
models/
  Hiyori/              ← Live2D 模特：模型文件 + model.json
    Hiyori.moc3  Hiyori.model3.json  Hiyori.2048/  ...
    model.json
  OneeSan/             ← 2D 立绘：图 + face.json + model.json
    body.png  face.json  model.json
```

`model.json`（Live2D）：
```json
{ "name": "我的角色", "type": "live2d", "model": "X.model3.json",
  "voice": "zh-CN-XiaoxiaoNeural", "zoom": 2.0, "y": 0 }
```

`model.json`（2D 立绘）：
```json
{ "name": "我的角色", "type": "puppet", "image": "body.png", "face": "face.json",
  "voice": "zh-CN-XiaoxiaoNeural", "zoom": 1.0, "y": 0 }
```

丢完回控制台点「刷新列表」即出现。**voice 换音色**：女 `zh-CN-XiaoxiaoNeural`，男 `zh-CN-YunxiNeural`（可加 `pitch`/`rate`）。

## 三、加一个新语料库（像装 mod）

往 `src/corpora/` 丢一个文件夹：

```
corpora/
  blindbox/            ← 语料库：人设 + 知识库 + 开场白
    corpus.json  faq.json
```

`corpus.json`：
```json
{
  "name": "盲盒带货·小七",
  "persona": "你是「小七」……（人设 + 说话规矩，事实锁死表达自由）",
  "faq": "faq.json",
  "loop_lines": ["开场白1", "开场白2", "开场白3"]
}
```

`faq.json`：`[{"q":"多少钱？","a":"69 一盒～"}, ...]`（同旧格式）。

丢完回控制台点「刷新列表」。切语料时后端自动**重建该语料的向量索引 + 换人设 + 换开场白**，实时生效。

## 四、改了什么

| 文件 | 改动 |
|---|---|
| `src/config.py` | 新增：扫 models/ + corpora/、读存当前组合（state.json）、switch API |
| `src/brain.py` | 人设从语料读（删写死的「小七」prompt） |
| `src/kb.py` | 按语料隔离 collection（`faq_<id>`），不再一个全局库 |
| `src/tts.py` | 声音/音调/语速从模特读（回退 .env） |
| `src/interaction_policy.py` | 开场白从语料读，`set_loop_lines()` 支持切换 |
| `src/orchestrator.py` | 加 `/api/config` `/api/active` `/api/switch`，切换广播 reload |
| `src/live2d_page/admin.html` | 新增：控制台切换面板 |
| `src/live2d_page/stage.html` | 新增：合并 Live2D + 立绘的统一渲染页 |
| `src/corpora/blindbox/` | 盲盒语料迁成 mod（原 faq.json 内容不变） |
| `src/live2d_page/Resources/models/` | 9 个模特，各带 model.json |

旧的 `index.html`（Hiyori）/ `oneesan.html`（御姐）原样保留，不影响，但新入口统一走 `stage.html`。

## 五、验证结果（无头浏览器 + API 实测）

- `GET /api/config`：9 模特 + 1 语料 + 当前组合 ✅
- `POST /api/switch` 切 Hiyori↔御姐：持久化到 state.json、live2d↔立绘重渲染，**零 JS 报错** ✅
- `brain.answer("这个多少钱？")`：DeepSeek 按「小七」人设回，情绪「平静」 ✅
- 立绘渲染非黑像素 62%、Live2D 正常出像（canvas 有内容、无 fatal） ✅

## 六、待办 / 可优化

1. 语料库现在还只有盲盒一个，新语料照 §三 丢文件夹即可。
2. 8 个 Live2D 样例是官方演示模型（日文名），要正式人设得换自己的模型（需 Cubism Editor 绑骨，见 v0.3 §一）。
3. `Resources/Candidates/`（官方样例的 git clone）已复制进 models/，原目录可删（省空间）。
4. 想按语料独立绑定声音（而非跟模特），把 voice 从 model.json 挪到 corpus.json 即可，改动很小。
