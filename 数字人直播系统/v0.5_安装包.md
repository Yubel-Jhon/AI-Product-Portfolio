# v0.5 · 桌面安装包（双击即用）

> 目标：把 v0.4 的「一条命令跑」变成「装完点图标就开」的桌面应用。
> 结果：Electron 壳 + 本机 Python 后端一起打进 NSIS 安装包，装完桌面/开始菜单有「动漫数字人」图标，点开即用，能换模特、换语料。

---

## 一、怎么装 / 怎么用

1. 跑 `npm run dist`（见 §二），`dist/` 里出 `AnimeDigitalHuman-Setup-0.5.0.exe`。
2. 双击安装包 → 选安装目录（可装桌面）→ 装完桌面有「动漫数字人」图标。
3. 点图标：Electron 自动拉起内置 Python 后端（约 30~40s 预热 BGE + 建索引），就绪后弹窗加载整合页。
4. 顶部下拉框切模特 / 切语料，实时生效。

## 二、怎么打安装包

```bash
cd /c/Users/Admin/Desktop/anime-digital-human
npm install --registry=https://registry.npmmirror.com   # 首次装依赖
CSC_IDENTITY_AUTO_DISCOVERY=false npm run dist           # 打 NSIS 安装包（不签名）
```

> 不签名：`CSC_IDENTITY_AUTO_DISCOVERY=false` + `win.signAndEditExecutable=false`。
> 原因：这台机器没开发者模式，electron-builder 解 winCodeSign（含 macOS 软链）会报「不能创建符号链接」，禁签名就跳过它。

## 三、打包后目录怎么算

Electron 主进程里（`electron/main.js`）：

- 开发跑（`npm start`）：资源在项目根目录，数据写 `src/`。
- 打包跑：资源在安装目录 `resources/`（含 `venv/`、`src/`、`.env`），**只读**；可写数据（`state.json`、`chroma_db/`、日志）统一写用户数据目录（`%APPDATA%\动漫数字人\`），由 `ADH_DATA_DIR` 环境变量指过去（`src/config.py` / `src/kb.py` 读它）。

## 四、改了什么

| 文件 | 改动 |
|---|---|
| `electron/main.js` | 支持打包模式：`resourcesPath` 找后端、`userData` 写日志/传 `ADH_DATA_DIR` |
| `src/config.py` | `state.json` 写目录可配置（`ADH_DATA_DIR`，默认 `BASE` 不变） |
| `src/kb.py` | `chroma_db` 写目录可配置（同上） |
| `package.json` | `version 0.5.0` + electron-builder 配置（extraResources 打包 venv/src/.env，NSIS 目标） |
| `.gitignore` | 加 `dist/`、冗余源文件（Candidates 官方样例 clone、立绘原始大图） |
| `v0.5_安装包.md` | 本文档 |

## 五、已知问题 / 待办

1. **安装包大（~1.5GB 解压）**：torch+transformers+chromadb 占大头，BGE 中文向量 + RAG 必须。可后续给 venv 瘦身（删 kubernetes/scipy/sklearn 等没用上的）。
2. **一个 Live2D 模型是 moc3 v6**，打包的 Cubism Core 是 v5，切到它会加载失败。正式用自己模型时不会遇到（要换 Core v6 或换模型）。
3. 安装包未签名，Windows SmartScreen 首次会提示「未知发布者」，点「仍要运行」即可。
4. `.env`（DeepSeek key）跟着打进安装包了，仅本机自用没问题；要分发得改成运行时填 key。
