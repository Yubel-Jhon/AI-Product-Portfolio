# 数字人 · 本地搭建操作清单（小白版）

> 目标：在你自己的电脑上，跑通「打字提问 → 它思考 → 开口说话」的本地闭环。**先出声音，画面最后加。**
> 本清单给 Windows + Git Bash（你的环境）。每一步都是「装什么 → 输什么命令 → 怎么算成功」。

---

## ⚠️ 动手前先读这 3 条（省你一整天的弯路）

### 1. 我把顺序调了：脸（画面）放最后

原来讲的概念顺序是「脸→嘴→脑→记忆→胶水」，但**实际动手顺序反过来最省事**：

| 动手顺序 | 做什么 | 难易 | 多久 |
|---|---|---|---|
| 第 0 步 | 装环境 | 中（就下载慢） | 30 分钟 |
| 第 1 步 | 嘴巴（声音） | 易 | 10 分钟 |
| 第 2 步 | 脑子（回答） | 易 | 15 分钟 |
| 第 3 步 | 记忆（防瞎编） | 易 | 30 分钟 |
| 第 4 步 | 胶水（串成能对话） | 中 | 1 小时 |
| 第 5 步 | 脸（会动嘴的画面） | **难** | 半天~1天 |

**为什么脸放最后**：前 1~4 步做完，你已经有一个「会对话的数字人」（只有声音、没画面）——**这个已经能演示、能录 demo、能写简历**。画面（Wav2Lip）是唯一难装、爱报错的零件，放到最后单独啃，别让它挡住你。

### 2. 用两个独立环境（这是新手第一大坑的解法）

不同工具要的依赖会打架。**分开装，各不干扰**：

- **环境 A（音频链路）**：edge-tts + openai + chromadb + sentence-transformers
- **环境 B（脸）**：Wav2Lip 单独一个环境

本清单默认**全部走「云端/CPU 路线」**（不需要显卡），有 N 卡再谈本地化提速。

### 3. 三条铁律

1. **报错就复制去问 AI**，一条条解，别自己硬扛。
2. **API key 别提交到 git**（下面会讲）。
3. **从第 4 步开始掐表测延迟**，目标「评论进来 → 开口 ≤ 10 秒」。

## 第 0 步：装环境（插座）

**要装 3 样：Python、Git、ffmpeg。**

### 0.1 装 Python

- 去 python.org 下载 **Python 3.10 或 3.11**，安装时**勾选「Add python.exe to PATH」**（关键）。
- 装完验证：

```bash
python --version      # 应显示 Python 3.10.x 或 3.11.x
pip --version         # 应显示 pip 版本
```

> 如果提示找不到 `python`，试 `py --version`。

### 0.2 装 Git

- 去 git-scm.com 下载安装，一路默认。
- 验证：

```bash
git --version
```

### 0.3 装 ffmpeg（后面 Wav2Lip 要用，现在顺手装了）

```bash
winget install Gyan.FFmpeg
```

装完**重开一个终端窗口**，验证：

```bash
ffmpeg -version
```

> 如果 winget 不行，就去 ffmpeg.org 手动下载 Windows 版，解压后把 `bin` 目录加进系统 PATH。

### 0.4 建项目文件夹 + 环境 A

```bash
mkdir -p ~/digital-human
cd ~/digital-human
python -m venv venv
source venv/Scripts/activate        # Git Bash 用这个（PowerShell 用 venv\Scripts\Activate.ps1）
```

成功标志：命令行前面出现 `(venv)`。**以后每次开新终端干活，都要先 `cd ~/digital-human` 再 `source venv/Scripts/activate`。**

## 第 2 步：脑子（评论 → 回答）

**目标**：输入评论文字，它回一句像样的答案。

### 2.1 装包

```bash
pip install openai
```

### 2.2 拿 DeepSeek 的 key

1. 打开 platform.deepseek.com，注册、登录。
2. 进「API Keys」，创建一个 key（`sk-` 开头），**复制存好，只显示一次**。

> DeepSeek 是国内服务，直连就能用，不用挂代理。这是选它的原因之一。

### 2.3 写测试文件

新建文件 `test_llm.py`（用记事本/VSCode 都行），内容：

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-把你的key粘这里",
    base_url="https://api.deepseek.com",
)

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是潮玩直播间客服。回答简短口语化。答案只能来自用户提供的信息，查不到就说查不到，禁止编造。"},
        {"role": "user", "content": "是正品吗"},
    ],
)
print(resp.choices[0].message.content)
```

运行：

```bash
python test_llm.py
```

**成功标准**：打印出一句自然的中文回答。

> **key 别写死在代码里再 git 提交。** 后面我们会把它抽到一个 `config.py`，并把 `config.py` 加进 `.gitignore`。

## 第 3 步：记忆（让它不瞎编）

**目标**：把潮玩 FAQ 存进一个「能按意思搜」的库，问它时先搜再答。

### 3.1 装包（torch 有点大，耐心等）

```bash
pip install chromadb sentence-transformers
```

> Windows 下 `pip install` 默认装 CPU 版 torch，约 200MB，正常。别装 CUDA 版，那是给有 N 卡的人省 GPU 的。

### 3.2 写测试文件

新建 `test_rag.py`：

```python
import chromadb
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("BAAI/bge-small-zh-v1.5")   # 首次运行会下载模型(~100MB)

client = chromadb.PersistentClient(path="./db")
col = client.get_or_create_collection("faq")

# 喂语料：你潮玩文档里的 FAQ（问题+答案都存，检索更准）
faqs = [
    ("1", "是正品吗", "官方正品授权，支持扫码验真"),
    ("2", "多久发货", "现货 48 小时内发出，预售按页面标注时间"),
    ("3", "隐藏款概率多少", "本系列隐藏款概率 1/96"),
    ("4", "能指定角色吗", "盲盒随机款式，不能指定；拍端盒保底一套常规款"),
    ("5", "端盒保底吗", "端盒保底一套常规款，隐藏款有机会额外出"),
    ("6", "有瑕疵怎么办", "联系客服，支持补件或换货"),
    ("7", "能退换吗", "未拆封支持 7 天无理由退换"),
    ("8", "包邮吗", "满 XX 元包邮，不满运费 XX 元"),
    ("9", "是现货还是预售", "现货款有标注，预售款按页面时间"),
    ("10", "什么材质", "PVC（手办）/ ABS+PVC（盲盒），官方工艺"),
]
ids = [f[0] for f in faqs]
docs = [f"{f[1]}：{f[2]}" for f in faqs]
col.add(ids=ids, documents=docs, embeddings=model.encode(docs).tolist())

# 查询测试
for q in ["多久发货", "隐藏款概率多少", "是正品吗"]:
    r = col.query(query_embeddings=model.encode([q]).tolist(), n_results=1)
    print(q, "→", r["documents"][0][0])
```

运行：

```bash
python test_rag.py
```

**成功标准**：三个问题都能搜出对应的标准答案，而不是乱答。

> 这一步成功后，把 `faqs` 里的内容换成你 `潮玩-话术脚本与知识库.md` 里的完整 12 条，再跑一次，全对即命中率 100%。

## 第 4 步：胶水（串成「能对话的数字人」）

**目标**：你打字 → 它检索 → LLM 想答案 → 开口说话。**这一步做完，你就有成品了（音频版）。**

### 4.1 把 key 抽出来

新建 `config.py`：

```python
LLM_KEY = "sk-把你的key粘这里"
```

新建 `.gitignore`（内容就一行，防止 key 被提交）：

```
config.py
```

### 4.2 写主程序

新建 `main.py`：

```python
import time, asyncio
import chromadb
from sentence_transformers import SentenceTransformer
from openai import OpenAI
import edge_tts
from config import LLM_KEY

VOICE = "zh-CN-XiaoxiaoNeural"
FALLBACK = "这个我暂时没查到，宝子可以点右下角咨询人工客服哦"

model = SentenceTransformer("BAAI/bge-small-zh-v1.5")
chroma = chromadb.PersistentClient(path="./db")
col = chroma.get_collection("faq")
llm = OpenAI(api_key=LLM_KEY, base_url="https://api.deepseek.com")

def retrieve(question):
    r = col.query(query_embeddings=model.encode([question]).tolist(), n_results=1)
    return r["documents"][0][0]

async def speak(text, out="reply.mp3"):
    await edge_tts.Communicate(text, VOICE).save(out)

def answer(comment):
    hit = retrieve(comment)
    resp = llm.chat.completions.create(
        model="deepseek-chat",
        messages=[
            {"role": "system", "content": (
                "你是潮玩直播间客服。只能根据下面这条知识回答，"
                "如果知识里没有答案，就只回复【兜底】两个字。"
                "回答口语化、一句话、50字以内。\n\n知识：" + hit
            )},
            {"role": "user", "content": comment},
        ],
    )
    text = resp.choices[0].message.content.strip()
    if "兜底" in text:
        text = FALLBACK
    return text

async def main():
    while True:
        comment = input("你（模拟观众评论）：")
        start = time.time()
        text = answer(comment)
        await speak(text)
        cost = time.time() - start
        print(f"数字人：{text}")
        print(f"耗时 {cost:.1f} 秒（目标 ≤10s）｜ 已生成 reply.mp3，双击播放\n")

asyncio.run(main())
```

### 4.3 跑起来

```bash
python main.py
```

然后输入你文档里的高频问题试：

```
你（模拟观众评论）：多久发货
你（模拟观众评论）：能指定角色吗
你（模拟观众评论）：今天天气怎么样   ← 知识库没有的，应触发兜底
```

**成功标准**：
- 商品问题 → 答对，且生成 `reply.mp3` 能听到它开口。
- 知识库没有的问题 → 它说兜底话术，**不瞎编**。
- 每轮打印的「耗时」≤ 10 秒。

> **到这一步，你已经有成品了。** 可以先录一段屏幕 demo。第 5 步只是给它加一张会动嘴的脸。

## 第 5 步：脸（会动嘴的画面）—— 最难，放最后

**目标**：把第 4 步生成的 `reply.mp3`，配上一张图，生成「嘴跟着声音动」的视频。

### 5.1 单独建环境 B（别用环境 A，会打架）

```bash
cd ~/digital-human
git clone https://github.com/Rudrabha/Wav2Lip.git
cd Wav2Lip
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
```

> **这一步八成会报错**（它的 requirements 很老，跟新版 Python/torch 常冲突）。报错就复制去问 AI 或看该仓库 Issues 里的解法。常见解法：
> - 用 conda 建一个 **Python 3.8** 环境专门跑它；
> - 或换一个维护更勤的 fork（搜「Wav2Lip fix python 3.10」）。

### 5.2 下载模型权重

去 Wav2Lip 仓库 README 里找 `wav2lip_gan.pth` 的下载链接（Google Drive），下好放到 `Wav2Lip/` 文件夹里。

### 5.3 准备一张正脸图

- 准备一张**正脸、清晰、露嘴**的图：动漫角色图（或你自己的照片）。
- 存成 `face.jpg`（放 Wav2Lip 文件夹里）。

### 5.4 把 mp3 转成 16k 单声道 wav（Wav2Lip 只认这个格式）

```bash
cd ~/digital-human
ffmpeg -i reply.mp3 -ar 16000 -ac 1 reply.wav
```

### 5.5 生成视频

```bash
cd ~/digital-human/Wav2Lip
python inference.py --checkpoint_path wav2lip_gan.pth --face face.jpg --audio ../reply.wav --outfile out.mp4
```

**成功标准**：打开 `out.mp4`，看到嘴在动，且和声音对得上。

> **关于速度**：CPU 跑这个很慢（几秒音频要几分钟）；有 N 卡会快非常多。这也是为什么我把它放最后——先把前面跑通，画面慢就慢点，能出结果就行。
