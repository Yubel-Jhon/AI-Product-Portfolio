# 潮玩数字人 · 话术脚本与商品知识库

> 垂类：潮玩（手办 / 盲盒 / 谷子）。这是「内容层」的落地产物——你个人可控的主战场，也是「动漫形象 + 实时交互」差异化最不违和的垂类。

---

## 0. 为什么潮玩适配「动漫数字人」（差异化自洽）

| 维度 | 潮玩特性 | 对数字人的好处 |
|---|---|---|
| 调性 | 二次元/IP 天然强关联 | 动漫形象不违和，反而更搭 |
| 信任门槛 | 客单价低、决策轻 | 观众更容易对「动漫数字人」下单 |
| 交互 | 买前高频问「正品/发货/隐藏款」 | 实时应答价值最大化 |
| SKU | 参数简单（尺寸/材质/IP） | 小模型 LLM + 知识库答得过来 |

## 1. 话术脚本（四段式，每段绑定形象）

> 每个段落的「形象」是「动漫引流 + 写实成交」策略的落点。

### 段1 · 开场引流（动漫形象）

- **目标**：3 秒内抓住停留，抛钩子，拉关注
- **示例话术**：
  - 「欢迎宝子们进来～这里是 XX 潮玩小铺的深夜档！今晚聊盲盒、拆手办，新来的先点个关注，一会儿有隐藏款开箱！」
  - 「别划走～二次元人集合！今晚这台盲盒机，隐藏款概率你猜是多少？答案马上揭晓，先点个关注不迷路。」

### 段2 · 商品讲解（写实形象）

- **目标**：把产品讲清、建立信任
- **示例话术**：
  - 「这款是 XX IP 的 XX 系列手办，高度约 15cm，PVC 材质，官方正品授权，现货。细节可以看下，涂装很稳，面雕还原度在线。」
  - 「盲盒一盒 6 个常规款，可能抽到隐藏款。材质是 ABS + PVC，实物比图片更有质感，拆盒过程很治愈。」

### 段3 · 卖点强化 / 逼单（写实形象）

- **目标**：强化信任 + 促成下单，说清交易细节
- **示例话术**：
  - 「这个系列 6 常规 + 1 隐藏，隐藏款概率 1/96。现在下单现货直发，48 小时内发出，支持 7 天无理由（未拆封）。」
  - 「想凑一套的宝子直接拍端盒，端盒保底一套常规款，隐藏款有机会连出。库存不多，拍完这波就下播。」

### 段4 · 收尾引导（动漫形象）

- **目标**：引导关注 / 下一场，留记忆点
- **示例话术**：
  - 「今晚的隐藏款开箱就到这啦，还没入手的宝子抓紧最后几分钟下单～明天同一时间继续拆盒，关注不迷路，下次见！」

## 2. 商品知识库字段设计（RAG 语料的结构）

> 这是「知识库」的最小可用字段。评论应答的答案只能从这里 + 商品库事实字段来，LLM 不编造。

### 2.1 商品基础字段

| 字段 | 类型 | 说明 | 是否事实字段（禁 LLM 编造） |
| --- | --- | --- | --- |
| 商品名称 | 文本 | 如「XX 系列 XX 角色手办」 | 是 |
| 品牌/IP | 文本 | 官方 IP / 工作室 | 是 |
| 系列 | 文本 | 所属系列 | 是 |
| 角色 | 文本 | 具体角色名 | 是 |
| 尺寸 | 数值+单位 | 如 15cm | 是 |
| 材质 | 枚举 | PVC / ABS / 树脂 | 是 |
| 价格 | 金额 | 实时取商品库 | **是（实时）** |
| 库存 | 数值 | 实时取商品库 | **是（实时）** |
| 是否现货 | 枚举 | 现货 / 预售 | 是 |
| 是否正品授权 | 布尔 | 官方授权 | 是 |

### 2.2 盲盒特有字段

| 字段 | 说明 | 事实字段 |
| --- | --- | --- |
| 常规款数量 | 一套几款 | 是 |
| 隐藏款概率 | 如 1/96 | 是 |
| 是否端盒 | 单抽 / 端盒 | 是 |
| 端盒保底 | 是否保底一套 | 是 |
| 能否指定角色 | 盲盒通常否 | 是 |

### 2.3 交易与售后字段

| 字段 | 说明 | 事实字段 |
| --- | --- | --- |
| 发货时效 | 现货 48h / 预售按页面 | 是 |
| 发货地 | 城市 | 是 |
| 运费 | 满 X 包邮 / 运费 X | 是 |
| 退换规则 | 未拆封 7 天无理由 | 是 |
| 瑕疵处理 | 补件 / 换货 / 退款 | 是 |

## 3. 高频 FAQ 语料（直接喂给知识库）

> 每条 = 「问题 → 标准答案」。评论应答时，命中最相似的这条，答案照抄，不改写、不发挥。

| # | 用户会问 | 标准答案（语料） |
| --- | --- | --- |
| 1 | 是正品吗 | 官方正品授权，支持扫码验真 |
| 2 | 多久发货 | 现货 48 小时内发出，预售按页面标注时间 |
| 3 | 隐藏款概率多少 | 本系列隐藏款概率 1/96 |
| 4 | 能指定角色吗 | 盲盒随机款式，不能指定；拍端盒保底一套常规款 |
| 5 | 端盒保底吗 | 端盒保底一套常规款，隐藏款有机会额外出 |
| 6 | 有瑕疵怎么办 | 联系客服，支持补件或换货 |
| 7 | 能退换吗 | 未拆封支持 7 天无理由退换 |
| 8 | 包邮吗 | 满 XX 元包邮，不满运费 XX 元 |
| 9 | 是现货还是预售 | 现货款有标注，预售款按页面时间 |
| 10 | 什么材质 | PVC（手办）/ ABS+PVC（盲盒），官方工艺 |
| 11 | 有没有 XX 角色 | 本系列角色有 A/B/C…（按实际库存列） |
| 12 | 价格多少 / 现在多少钱 | 实时取商品库价格（**不固定写死，动态调用**） |

## 4. 兜底与敏感词（防翻车）

### 4.1 未命中兜底话术

- 「这个我暂时没查到，宝子可以点右下角咨询人工客服，看到马上回你～」

### 4.2 敏感/违规（直接静默，不回应）

- 涉政、涉黄、人身攻击、平台违禁词
- 诱导私下交易（「加微信」「转账」）→ 提示「请走平台正规下单，安全有保障」

### 4.3 未经授权承诺（禁止数字人说）

- ❌「买一送十」「假一赔百」「绝对会中隐藏款」
- ✅ 只能说知识库/商品库里写好的事实
